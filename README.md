## 🇻🇳 Bối cảnh — Luật Bản Quyền Phần Mềm tại Việt Nam năm 2026

Từ đầu năm 2026, cơ quan chức năng Việt Nam đẩy mạnh các đợt thanh tra, kiểm tra việc sử dụng phần mềm không có bản quyền tại doanh nghiệp và hộ kinh doanh. Theo **Nghị định 17/2023/NĐ-CP** và **Luật Sở hữu trí tuệ sửa đổi 2022**:

| Đối tượng | Mức phạt hành chính |
|---|---|
| Cá nhân vi phạm | **500.000 – 250.000.000 VNĐ** |
| Tổ chức / Doanh nghiệp | **1.000.000 – 500.000.000 VNĐ** |
| Vi phạm thương mại quy mô lớn | **Truy cứu trách nhiệm hình sự** |

> ⚠️ **Các phần mềm thường bị kiểm tra nhất:** Microsoft Office, Windows, Adobe Photoshop/Illustrator/Premiere, CorelDRAW, AutoCAD, các phần mềm kế toán và ERP không có hợp đồng bản quyền hợp lệ.

**LicenseChecker** được tạo ra để giúp bạn chủ động kiểm tra, nắm rõ tình trạng bản quyền của từng phần mềm đang cài đặt — và tìm ngay giải pháp thay thế miễn phí / mã nguồn mở khi cần.

## 🚀 Cài đặt

### Yêu cầu hệ thống
- **Windows** 10 / 11 (64-bit)
- **Python** 3.8 trở lên
- Kết nối Internet *(khuyến nghị — để tải DB mới nhất từ GitHub)*

### Cài đặt nhanh

```bash
# 1. Clone repository
git clone https://github.com/HuynhDucTung/LicenseChecker.git
cd LicenseChecker

# 2. Cài thư viện (tuỳ chọn — chỉ cần nếu dùng tính năng Import Excel)
pip install openpyxl

# 3. Chạy
python LicenseChecker.py
```

### Đóng gói thành file .exe *(không cần cài Python)*

```bash
pip install pyinstaller
pyinstaller --onefile --windowed --icon=icon.ico LicenseChecker.py
# File .exe xuất hiện tại: dist/LicenseChecker.exe
```

## 📖 Hướng dẫn sử dụng

### Bước 1 — Quét phần mềm

Khởi động chương trình → Tab **"Quét & Phân Tích Bản Quyền"** sẽ tự động quét sau 400ms. Nhấn **⟳ Quét lại** bất cứ lúc nào.

> Chương trình đọc danh sách phần mềm từ **Windows Registry** — đúng với những gì Windows ghi nhận, không cần quyền Administrator trong hầu hết trường hợp.

### Bước 2 — Đọc kết quả

- Nhấn các nút **danh mục** để lọc theo nhóm
- Dùng ô **Tìm kiếm** để lọc nhanh theo tên
- Nhấn **tiêu đề cột** để sắp xếp
- Nhấn **đúp chuột** vào một phần mềm → mở trang tải phần mềm thay thế
- Nhấn **chuột phải** → menu ngữ cảnh với nhiều tùy chọn

### Bước 3 — Xử lý phần mềm vi phạm

**Phương án A — Mua bản quyền hợp lệ:**
→ Nhấn phải → *"Tìm bản quyền / giá mua"* → tra Google

**Phương án B — Thay thế bằng phần mềm miễn phí:**
→ Chuyển sang Tab **"Kho Phần Mềm Miễn Phí"**
→ Chọn phần mềm thay thế → nhấn **⬇ Tải về**

**Phương án C — Gỡ cài đặt:**
→ Dùng **Bulk Crap Uninstaller** hoặc **Revo Uninstaller** để gỡ sạch

### Bước 4 — Xuất báo cáo

Nhấn **📊 Xuất báo cáo** → lưu file `.txt` với đầy đủ danh sách theo nhóm bản quyền. Có thể dùng làm hồ sơ nội bộ kiểm soát bản quyền phần mềm cho doanh nghiệp.

## 🌐 Cơ sở dữ liệu Online

Khi khởi động, LicenseChecker tự động tải cơ sở dữ liệu mới nhất từ GitHub:

```
https://raw.githubusercontent.com/HuynhDucTung/LicenseChecker/main/software_data.json
```

| Trạng thái | Hiển thị | Hành vi |
|---|---|---|
| Có Internet | `🌐 DB: GitHub (online)` | Tải mới, cache lại local |
| Mất Internet | `💾 DB: Local (offline)` | Dùng bản cache lần trước |

Nhấn **🔄 Tải lại DB** để cập nhật thủ công bất cứ lúc nào.

### Cấu trúc `software_data.json`

```jsonc
[
  {
    "id": "libreoffice",
    "name": "LibreOffice",
    "keywords": ["libreoffice"],          // Từ khoá nhận dạng (chữ thường)
    "license": "Mã nguồn mở",            // Loại bản quyền
    "category": "Ứng dụng văn phòng",    // Danh mục theo download.com.vn
    "alt": "",                            // Phần mềm thay thế (nếu có)
    "alt_url": "",                        // Link tải thay thế
    "note": "Bộ Office mã nguồn mở ✓",  // Ghi chú hiển thị
    "free_catalog": {                     // null nếu không có trong Tab 2
      "desc": "Thay thế hoàn toàn Microsoft Office",
      "url": "https://www.libreoffice.org/download/"
    }
  }
]
```

**Các giá trị `license` hợp lệ:**
`Mã nguồn mở` · `Miễn phí` · `Freemium` · `Thương mại` · `Dùng thử` · `Chưa rõ`

**Các `category` theo download.com.vn/windows:**
`Ứng dụng văn phòng` · `Phần mềm Hệ thống` · `Thiết kế đồ họa` · `Chỉnh sửa ảnh` · `Phần mềm Video` · `Nghe nhạc` · `Trình duyệt` · `Chat & Gọi video` · `Bảo mật` · `Diệt Virus - Spyware` · `Phần mềm mạng` · `Hỗ trợ Download` · `Phần mềm lập trình` · `Quản lý Doanh nghiệp` · `Dữ liệu - File` · `Quản trị CSDL` · `Giáo dục - Học tập` · `Phần mềm cá nhân` · `Mạng xã hội` · `Quản lý Email` · `Drivers - Firmware`

## 🤝 Đóng góp cộng đồng

Cơ sở dữ liệu chỉ mạnh khi cộng đồng cùng đóng góp!

### Cách 1 — Trực tiếp trong phần mềm *(dễ nhất)*

1. Chạy LicenseChecker, quét phần mềm
2. Tìm phần mềm **chưa có trong DB** *(màu xám, loại "Chưa rõ")*
3. **Nhấn chuột phải** → **"➕ Thêm '[tên phần mềm]' vào CSDL ★"**
4. Điền thông tin vào form → nhấn **"🌐 Lưu & Đóng góp lên GitHub"**
5. Trình duyệt mở GitHub Issues đã điền sẵn → **Submit new issue**

> Maintainer sẽ review và merge vào `software_data.json` — toàn bộ người dùng nhận được ngay lần tải tiếp theo!

### Cách 2 — Pull Request trực tiếp

```bash
git clone https://github.com/HuynhDucTung/LicenseChecker.git
# Chỉnh sửa software_data.json
# Đảm bảo: "id" và tất cả "keywords" là duy nhất
git add software_data.json
git commit -m "feat: thêm [Tên phần mềm]"
git push origin main
# Tạo Pull Request
```

### Cách 3 — Import từ Excel

Chuẩn bị file `.xlsx` với cấu trúc:

| A — TenPhanMem | B — LoaiBanQuyen | C — DanhMuc | D — PhanMemThayChe | E — URLTaiVe | F — GhiChu |
|---|---|---|---|---|---|
| Tên phần mềm | Loại bản quyền | Danh mục | Tên thay thế | https://... | Ghi chú ngắn |

→ Nhấn **📂 Nạp DB từ Excel** trong Tab 1

```
Bước 1  →  Chạy LicenseChecker trên từng máy tính
```

## ❓ Câu hỏi thường gặp

<details>
<summary><b>🔍 Phần mềm tôi dùng không xuất hiện trong kết quả quét?</b></summary>

Một số phần mềm "portable" (không cài đặt) không ghi vào Registry nên LicenseChecker không phát hiện được. Bạn cần kiểm tra thủ công hoặc thêm vào DB qua tính năng "Thêm mới".

</details>

<details>
<summary><b>🟡 Phần mềm hiện màu xám "Chưa rõ" nghĩa là gì?</b></summary>

Phần mềm đó chưa có trong cơ sở dữ liệu. Không nhất thiết là vi phạm — hãy tìm hiểu và nhấn phải → **"Thêm vào CSDL"** để đóng góp cho cộng đồng.

</details>

<details>
<summary><b>💾 Dùng được khi mất Internet không?</b></summary>

Có. LicenseChecker cache bản DB mới nhất vào `software_data.json` sau mỗi lần tải thành công. Khi mất Internet, chương trình tự dùng bản local đã cache.

</details>

<details>
<summary><b>🪟 Windows tôi đang dùng có bị kiểm tra không?</b></summary>

Có. Windows không có bản quyền (key không hợp lệ hoặc dùng activator) cũng là vi phạm bản quyền. LicenseChecker phát hiện Windows trong danh sách phần mềm hệ thống nhưng **không thể kiểm tra trạng thái kích hoạt**. Kiểm tra bằng: `Settings → System → Activation`.

</details>

<details>
<summary><b>📊 Tôi có thể dùng báo cáo để nộp cho cơ quan thanh tra không?</b></summary>

Báo cáo từ LicenseChecker có thể dùng làm tài liệu tham khảo nội bộ. Tuy nhiên, để có giá trị pháp lý đầy đủ, bạn cần kết hợp với hợp đồng mua bản quyền gốc và có thể cần xác nhận từ các nhà cung cấp phần mềm.

</details>

<details>
<summary><b>🔄 Cập nhật DB thủ công như thế nào?</b></summary>

Nhấn nút **🔄 Tải lại DB** trong Tab 1 → chương trình kéo phiên bản mới nhất từ GitHub trong nền, không làm gián đoạn thao tác.

</details>
